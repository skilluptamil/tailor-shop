1. Template Overview & Key Features

Sartoria Royale is a luxury, responsive HTML5 template crafted for tailoring shops, fashion boutiques, bespoke ateliers, and alteration salons. Built on modern CSS variables, Bootstrap 5 grid, and modular vanilla JavaScript with zero build steps required.

  • 2 Distinct High-Converting Homepages (Classic Tailoring + Haute Couture Boutique)
  • Complete Suite of 12+ Tailoring & Alteration Pages
  • Native Dark / Light Theme switcher with localStorage memory
  • Complete RTL (Right-to-Left) Language stylesheet for Arabic & Hebrew
  • Interactive Live Filtering for Services, Portfolio, Fabrics, and Blog
  • Interactive Admin Dashboard with Chart.js analytics & Measurement archives
  • Fully responsive and mobile optimized (320px to 4K displays)

3. Color Customization

All colors are centrally managed in assets/css/style.css using native CSS variables. Simply edit the variables inside :root to re-brand the entire template in seconds:

:root {
  --color-primary: #171513;        /* Deep Charcoal / Noir */
  --color-secondary: #C5A880;      /* Sartorial Champagne Gold */
  --color-accent: #6B1D2F;         /* Royal Burgundy */
  --bg-sand: #F7F3EB;              /* Warm Ivory Sand */
  --bg-surface: #FFFFFF;           /* Card White */
  --text-main: #4A4641;            /* Body Text */
  --text-heading: #171513;         /* Headings */
}

4. Typography Setup

The template pairs Playfair Display and Cormorant Garamond for editorial luxury headings with Plus Jakarta Sans for clean, ultra-readable body text:

--font-heading: 'Playfair Display', serif;
--font-editorial: 'Cormorant Garamond', serif;
--font-body: 'Plus Jakarta Sans', sans-serif;

5. Dark Mode & RTL Direction

Dark mode and RTL are completely automated via JavaScript and CSS data attributes:

  • Dark Theme: Triggered via [data-theme="dark"] attribute on <html>. Managed by assets/js/theme.js.
  • RTL Direction: Triggered via [dir="rtl"] on <html>. Managed by assets/js/rtl.js and styled via assets/css/rtl.css.

6. Form Validations & Notifications

All forms include HTML5 validation hooks managed by assets/js/validation.js. To trigger a custom toast programmatically anywhere in your code:

window.sartoriaValidation.showToast('Your custom message here!', 'success');
